# # iRafa.com

Projeto de desenvolvimento de uma página web inspirada em sites de entretenimento e cultura pop, utilizando HTML, CSS e JavaScript.

O projeto foi desenvolvido com foco na criação de uma interface visual personalizada, trabalhando com estrutura de página, estilização, imagens, fontes e interações utilizando JavaScript.

## Sobre o projeto

O iRafa.com é uma página web criada para praticar desenvolvimento front-end e construção de interfaces utilizando tecnologias básicas da web.

A proposta do projeto é desenvolver uma identidade visual própria para o site, utilizando elementos gráficos, fontes personalizadas, imagens e componentes estruturados em HTML e CSS.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Arquivos principais

### index.html

Arquivo responsável pela estrutura e pelo conteúdo principal da página.

### style.css

Arquivo responsável pela estilização do projeto, incluindo:

- Cores
- Tipografia
- Posicionamento dos elementos
- Dimensões
- Bordas
- Espaçamentos
- Organização visual da página

### script.js

Arquivo responsável pelas funcionalidades e interações desenvolvidas em JavaScript.

### Fontes

O projeto possui fontes personalizadas utilizadas para contribuir com a identidade visual da página:

- Coolvetica Rg Cond
- Triac 71

### Imagens

As imagens presentes no projeto são utilizadas como elementos visuais da página e fazem parte da composição da interface.

## Como executar o projeto

Como o projeto utiliza HTML, CSS e JavaScript, não é necessário instalar dependências para visualizar a página.

### 1. Clonar o repositório

```bash
git clone https://github.com/Higor552/iRafa.com.git
```

### 2. Entrar na pasta

```bash
cd iRafa.com
```

### 3. Abrir o projeto

Abra o arquivo `index.html` em um navegador.

Também é possível abrir a pasta no Visual Studio Code e utilizar uma extensão como o Live Server para visualizar o projeto durante o desenvolvimento.

## Objetivos

O projeto tem como principais objetivos:

- Praticar desenvolvimento front-end.
- Trabalhar com HTML, CSS e JavaScript.
- Desenvolver uma identidade visual própria.
- Utilizar fontes personalizadas.
- Trabalhar com imagens e elementos gráficos.
- Criar uma página web organizada e responsiva.

## Desenvolvimento

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web, permitindo trabalhar desde a estrutura da página até sua aparência e interatividade.

A separação entre HTML, CSS e JavaScript facilita a organização do código e permite que cada parte do projeto tenha uma função específica.
